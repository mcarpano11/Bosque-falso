# SILVA AETERNA

Grimorio digital **totalmente ficticio**, hecho para jugar con símbolos de bosques, raíces y un gato guardián. No tiene efectos mágicos ni actúa sobre personas, dispositivos o propiedades.

## Probarlo

Abre `index.html` en un navegador. Pulsa **ACTIVAR SELLO FICTICIO** para ver una animación y un contador que se reinicia al cerrar o recargar la página.

## Publicarlo en GitHub Pages

1. Crea un repositorio público nuevo en GitHub.
2. Sube `index.html` y este `README.md` (y `LICENSE`, si deseas).
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. Espera a que GitHub muestre la URL del sitio.

## Privacidad y anonimato

- El proyecto no incluye nombres reales, fotos, direcciones, coordenadas, cuentas ni datos personales.
- No usa bibliotecas externas, cookies, almacenamiento local, formularios, estadísticas ni solicitudes de red programadas.
- **Importante:** publicar en GitHub no garantiza anonimato. Tu nombre de usuario, perfil, historial de commits, correo de autor de Git, hora de publicación y actividad de GitHub pueden revelar información. Usa una cuenta seudónima, revisa la privacidad de tu perfil y configura el correo `noreply` de GitHub antes de publicar. GitHub y el alojamiento pueden registrar visitas según sus propias políticas.
- Revisa los archivos antes de subirlos y evita subir imágenes con metadatos o archivos privados.
